# VampireDrift (Godot 4.x)

This is a 3D Vampire Survivors-like game with car physics (inspired by Fumes/Twisted Metal).

## Features
- **Drift Physics:** Arcade-style car controls with sliding.
- **Auto-Combat:** Turret system that targets nearest enemies.
- **Endless Waves:** Enemies spawn around the player.
- **Destruction:** Particle effects and physics collisions.

## How to Run
1. Download Godot 4.x (Tested on 4.5).
2. Open Godot and click "Import".
3. Select the `project.godot` file in this folder.
4. Click "Run" (Play button) or press F5.

## Controls
- **Arrow Keys / WASD:** Accelerate, Brake, Steer.
- **Goal:** Survive as long as possible and destroy red enemy boxes.
